# הבריאות של דבי — הוראות

האפליקציה היא דף אינטרנט סטטי — בלי שרת ובלי חשבון. הנתונים נשמרים רק בטלפון שבו היא פתוחה.

**הקבצים (כולם צריכים להיות באותה תיקייה / באותו מאגר):**
| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה |
| `manifest.json` | מגדיר את הדף כאפליקציה (שם, אייקון, מסך מלא) — בלי זה כרום מציע רק "קיצור דרך" |
| `sw.js` | Service Worker — מאפשר התקנה אמיתית ועבודה אופליין |
| `icon-192.png`, `icon-512.png` | אייקון למסך הבית |

## איך לשלוח לדבי (בדיקה ראשונה)
1. שלח את `index.html` בוואטסאפ / מייל לטלפון שלה.
2. היא פותחת את הקובץ — בדרך כלל נפתח בדפדפן.

**חשוב:** קובץ שנפתח מוואטסאפ נפתח לפעמים כעותק חדש בכל פעם, ואז הנתונים לא נשמרים בין פתיחות (בעיקר באייפון). זה טוב לבדיקה, לא לשימוש יומיומי. לשימוש קבוע — ראה "העלאה לאינטרנט" למטה.

## העלאה לאינטרנט (חינם, מומלץ לשימוש קבוע)
עם GitHub Pages הקובץ מקבל כתובת קבועה, אפשר להוסיף למסך הבית כאפליקציה, והנתונים נשמרים באמינות.

1. פתח חשבון ב-github.com (אם אין).
2. צור מאגר (Repository) חדש, למשל בשם `debbie-health`, סמן **Public**.
3. לחץ **Add file → Upload files**, גרור את **כל 5 הקבצים** (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`), ולחץ **Commit changes**.
4. במאגר: **Settings → Pages → Branch: main → Save**.
5. אחרי כדקה תופיע כתובת כמו `https://<שם-משתמש>.github.io/debbie-health/` — שלח אותה לדבי.

לעדכון גרסה: מעלים שוב את הקבצים שהשתנו (בדרך כלל רק `index.html`) — GitHub מחליף את הקודמים. הנתונים של דבי לא נפגעים — הם בטלפון שלה, לא בקובץ.

## הוספה למסך הבית (כמו אפליקציה)
- **אייפון (Safari):** פותחים את הכתובת ב-Safari → כפתור שיתוף (ריבוע עם חץ) → **הוסף למסך הבית**.
- **אנדרואיד (Chrome):** פותחים את הכתובת → תפריט ⋮ → **התקן אפליקציה** (או "הוסף למסך הבית" → **התקן**). אם מופיע רק "צור קיצור דרך" — לרענן את הדף פעם-פעמיים ולנסות שוב; כרום צריך לטעון קודם את `manifest.json` ו-`sw.js`.

## גיבוי
- בטאב **יומן ועוד → גיבוי → ייצוא גיבוי** נוצר קובץ JSON. אפשר לשלוח אותו לעצמך בוואטסאפ.
- **ייבוא גיבוי** מחזיר הכל מהקובץ (למשל אחרי החלפת טלפון).
- **שחזור מהגיבוי הפנימי** — האפליקציה שומרת אוטומטית את הגרסה הקודמת של הנתונים לפני כל שמירה. אם משהו השתבש, זה מחזיר צעד אחד אחורה.

## מה יש בגרסה 1
- **היום** — המסך היחיד שצריך ביום־יום: מים, הארוחה הבאה, "מה כדאי לי לאכול עכשיו?" (3 הצעות לפי שעה / מה כבר נאכל / מועדפים), מצב "אין לי כוח", מצב רוח ואנרגיה, תזכורת לדיווח שינה, ופעולות מהירות בתחתית. בנוסף: "איזון היום" (אילו קבוצות תזונה כוסו), המלצות חלבון אם עוד לא היה חלבון עד הצהריים, ושגרת לילה לסימון ישירות מהבית.
- **תפריט** — תפריט שבועי אוטומטי רק ממה שמסומן "אוכלת", עדיפות למועדפים, בלי חזרות מיותרות, מנות שבת בשבת; רשימת קניות מאוחדת עם "יש בבית" והוספה ידנית.
- **מאכלים** — מאגר עם סוג פריט, קטגוריה, קבוצות תזונה (חלבון / פחמימה / ירקות / חלבי / שומן בריא), זמן הכנה, רמת מאמץ, מרכיבים, ⭐ מועדפים. ברירת המחדל מציגה רק "אוכלת".
- **שינה** — דיווח לילה, שגרת לילה, גרף 14 יום וממוצע שבועי.
- **יומן ועוד** — השבוע במבט אחד, פירוט יומי, גובה ומשקל (גרף + BMI), הגדרות, גיבוי.
